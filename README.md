# 手机助手（ios-mcp-agent）

装在 iPhone 上。输入一句话，模型自己拆成步骤，App 把每一步原样转发给本机 ios-mcp（`127.0.0.1:8090`）。App 不决定怎么点、怎么滑。

开发者：liush
开源主页：https://github.com/liush734530963/ios-mcp-agent-public

## 📖 使用说明

1. 这台 iPhone 已安装 [iOS MCP](https://github.com/witchan/iOS-MCP)，设置里服务开着。Safari 打开 `http://127.0.0.1:8090/health`，要能看到 `status:ok`。
2. 打开 App，点右上角「模型」。ios-mcp 地址保持 `http://127.0.0.1:8090`。
3. 填你自己的模型接口（以 `/v1` 结尾）、密钥、模型名，点保存。模型要能调用工具；需要看屏幕时还要能看图。
4. 回到主界面，输入要做的事，例如：`帮我打开微信，找到好友ZZ发信息`。点开始。
5. 左上角「关于」有同样的说明与更新日志。

8090 是这台手机自己的端口。App 和 ios-mcp 必须装在同一台手机上。锁屏时 ios-mcp 会拦住点击和输入，每轮开始会先唤醒并回主屏。

公开版不带任何密钥。密钥只保存在这台手机上。

## 边界说明

- 只转发工具调用。工具名与 ios-mcp 原生一致。
- `done` / `fail` 由模型决定收尾，App 负责安全终止与释放保活。
- `run_command` 能跑任意 shell，仅在个人受信手机环境中使用。
