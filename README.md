# 手机助手（ios-mcp-agent）

装在 iPhone 上。输入一句话，模型自己拆成步骤，App 把每一步原样转发给本机 ios-mcp（`127.0.0.1:8090`）。App 不决定怎么点、怎么滑。

开发者：liush
开源主页：https://github.com/liush734530963/ios-mcp-agent-public

## 📖 使用与安装指引

### 1. 越狱设备与 iOS-MCP 底层服务安装
- **服务依赖**：AI 自然语言全自动驱动屏幕、模拟点击/滑动、读取原生 UI 元素树依赖本机 `127.0.0.1:8090` 端口守护进程。
- **安装方法**：在越狱设备（Dopamine 等越狱环境，需具备 ElleKit 框架支持）的包管理器中安装 [iOS MCP](https://github.com/witchan/iOS-MCP) 插件或其 Deb 包。
- **健康检查**：安装后在 iPhone 的 Safari 浏览器打开 `http://127.0.0.1:8090/health`，若页面返回 `{"status":"ok"}` 则表示服务已正常运行。App 首页顶部状态卡片将自动亮起绿色「🟢 iOS-MCP 8090 在线」。

### 2. 纯巨魔免越狱设备（无需 iOS-MCP）
- 纯巨魔（TrollStore）由于未越狱无法注入 SpringBoard，无法运行 iOS-MCP 8090 服务。
- 但无需担心：纯巨魔用户可直接使用右上角「定时/工作流」功能，支持后台无感常驻、深浅色外观切换、软注销桌面、勿扰模式、URL 应用调起，以及专为巨魔设计的「0 亮度纯黑伪熄屏挂机」功能。

### 3. 配置模型与开始使用
1. 打开 App，点右上角「模型」。
2. 填你自己的模型接口（以 `/v1` 结尾）、密钥、模型名，点保存。
3. 回到主界面，输入要做的事，例如：`帮我打开微信，找到好友ZZ发信息`。点开始。

## 📦 两个安装包说明

每次推送会编两个未签名 IPA，用 TrollStore 安装：

- `ios-mcp-agent-public-{版本}-{构建号}.ipa`：公开版，模型三项留空，无任何敏感信息。
- `ios-mcp-agent-personal-{版本}-{构建号}.ipa`：自用版。打包流水线自动注入 DeepSeek（`api.deepseek.com`，模型 `deepseek-flash`）和 pengdan（`api.pengdan.eu.org`，模型 `gemini-3.8-flash-high`）。密钥来自仓库 Secrets，不进入 Git 源码。

## 边界说明

- 只转发工具调用。工具名与 ios-mcp 原生一致。
- `done` / `fail` 由模型决定收尾，App 负责安全终止与释放保活。
- `run_command` 能跑任意 shell，仅在个人受信手机环境中使用。
