v1.0.5：全屏 web 壳（与电脑桌面端一致）+ 联网即自动加载会话

UI 布局（对标 Hermes Studio iOS）：
- 移除原生地址栏与工具栏，WKWebView 四边贴满 view，不吃 safeArea，
  scrollView.contentInsetAdjustmentBehavior = .never，观感等同桌面端
- SceneDelegate 去掉 UINavigationController，rootViewController 直接是 ViewController
- 右下角保留一个 40x40 半透明圆按钮（alpha 0.35）浮在 web 之上，
  点开才能换地址/看版本，默认几乎不可见，不干扰桌面端观感

联网即加载会话：
- 新增 NWPathMonitor 监听，网络从无到有（.satisfied）且处于失败态/尚未加载时自动重连
- 监听 UIApplication.didBecomeActiveNotification，回到前台同样条件自动重连
- retryTapped 改为：有当前 URL 就重载，否则回到默认 3083 地址

其他：
- 错误浮层新增「换一个地址」按钮直达服务菜单
- 服务列表改为 pageSheet modal 呈现，新增 done 关闭按钮，选中即 dismiss/pop
- bump-version.ps1 重写为纯 ASCII（PowerShell 5.1 读无 BOM UTF-8 会乱码）
